KobiChat — güncelleme (Microsoft Store)

==================================================

Kurulu uygulama güncellemeleri yalnızca Microsoft Store üzerinden dağıtılır.

• Ayarlar → "Microsoft Store'da güncelle" veya tepsi menüsü aynı Store sayfasını açar.
• Web: https://apps.microsoft.com/detail/9N01GLSS1KBJ
• Store uygulaması: ms-windows-store://pdp/?productid=9N01GLSS1KBJ

GitHub otomatik güncelleme (electron-updater) uygulama içinde devre dışıdır.

Geliştirici / yayın
-------------------

• Microsoft Store paketi: npm run release:store
• İsteğe bağlı NSIS kurulum (iç dağıtım): npm run release:win:local — GitHub release;
  kurulu uygulama yine Store'a yönlendirir.

Store listesi: build/store-identity.json
